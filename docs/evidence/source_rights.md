## NYC TLC Yellow Taxi

- Dataset: January 2024 Yellow Taxi Trip Records, Parquet.
- Discovery page: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
- File URL: https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2024-01.parquet
- NYC Open Data says public datasets have no use restrictions, though additional terms from the submitting agency may apply.
- TLC does not guarantee that submitted trip records are accurate or complete, and notes that schemas may change.
- If republishing, identify the source, version, and modifications.
- Project use: personal, noncommercial learning. Keep source bytes private while we build and validate the pipeline; public redistribution is a separate decision.

- API documentation: https://open-meteo.com/en/docs/historical-weather-api
- Terms: https://open-meteo.com/en/terms
